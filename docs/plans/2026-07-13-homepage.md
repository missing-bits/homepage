# Missing Bits Homepage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and deploy the bilingual (EN/PL) static Missing Bits homepage to GitHub Pages at `missing-bits.com`.

**Architecture:** Astro static site with built-in i18n (`prefixDefaultLocale: true`): all copy in per-locale JSON, locale-invariant data in `src/data/`, one component per section, a language detector at `/`, GitHub Actions deploy to Pages, DNS in Route 53. Spec: `docs/specs/2026-07-13-homepage-design.md`.

**Tech Stack:** Astro 7 (pinned `^7`), @astrojs/sitemap, sharp (dev-only, icon generation), Node 24 via mise, GitHub Actions (`withastro/action`), GitHub Pages, AWS Route 53.

## Global Constraints

- Glossary (`docs/domain/glossary.md`) binds all copy and naming: the artifact is the **homepage** (never "landing page", "business card", "site"); content languages are **locales** (`en`, `pl`, default `en`); the company is **"Missing Bits"** — two words in text, `MissingBits` only inside the wordmark graphic.
- No test framework — `npm run build` is the gate; each task verifies by building and inspecting `dist/`.
- Zero runtime JavaScript except: the language detector inline script on `/` and the locale-persisting one-liner in the language switcher.
- No CSS framework; no external requests at runtime (system font stack, self-hosted assets).
- Host-level tools (Node, gh, …) are installed EXCLUSIVELY via mise. Project libraries are npm dependencies in `package.json`, installed with mise's Node — never `npm install -g`.
- All committed documents and code comments in English. Conventional Commits, single subject line, no body, no trailers.
- Commits land on `master` (the default branch) — ONLY with the developer's explicit authorization given at execution start; push only when the developer authorizes it.
- Repository: `missing-bits/homepage` (exists, currently private). The Route 53 hosted zone ID for `missing-bits.com` is resolved at runtime, never hardcoded: `ZONE_ID=$(aws route53 list-hosted-zones --query "HostedZones[?Name=='missing-bits.com.'].Id" --output text)`.
- GitHub operations use the developer-authenticated `gh` CLI; where raw REST calls are needed, authenticate them with `TOKEN=$(gh auth token)` and `curl -H "Authorization: token $TOKEN" https://api.github.com/...`. Never print or commit tokens.
- Site URL everywhere: `https://missing-bits.com` (apex; `www` redirects to it).

```js
import sharp from 'sharp';

const transparent = { r: 0, g: 0, b: 0, alpha: 0 };

async function icon(size, file) {
  await sharp('src/assets/logo/mb_hexagon.png')
    .resize(size, size, { fit: 'contain', background: transparent })
    .png()
    .toFile(`public/${file}`);
}

await icon(32, 'favicon-32.png');
await icon(180, 'apple-touch-icon.png');
await icon(512, 'icon-512.png');

const wordmark = await sharp('src/assets/logo/mbw_wordmark.png')
  .resize({ width: 900 })
  .png()
  .toBuffer();

await sharp({ create: { width: 1200, height: 630, channels: 4, background: '#0b1020' } })
  .composite([{ input: wordmark, gravity: 'center' }])
  .png()
  .toFile('public/og-image.png');

console.log('icons + og-image written to public/');
```

- [ ] **Step 1: Create the shared detector — src/components/LocaleRedirect.astro**

Contract from the spec: inline synchronous script in `<head>` redirects immediately (saved `localStorage` choice → `navigator.language` → `en`); the meta refresh carries a 2-second delay so it only wins when JS never runs. Both unprefixed paths (`/`, `/contact/`) use this component and differ only in `path`.

```astro
---
interface Props { path: string } // '' → /en/ | /pl/ ; 'contact/' → /en/contact/ | /pl/contact/
const { path } = Astro.props;
const site = 'https://missing-bits.com';
---
<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <script is:inline define:vars={{ path }}>
      var saved = null;
      try { saved = localStorage.getItem('locale'); } catch (e) {}
      var target =
        saved === 'pl' || saved === 'en'
          ? saved
          : ((navigator.language || '').toLowerCase().indexOf('pl') === 0 ? 'pl' : 'en');
      location.replace('/' + target + '/' + path);
    </script>
    <meta http-equiv="refresh" content={`2;url=/en/${path}`} />
    <meta name="robots" content="noindex" />
    <title>Missing Bits</title>
    <link rel="alternate" hreflang="en" href={`${site}/en/${path}`} />
    <link rel="alternate" hreflang="pl" href={`${site}/pl/${path}`} />
    <link rel="alternate" hreflang="x-default" href={`${site}/${path}`} />
  </head>
  <body>
    <p><a href={`/en/${path}`}>English</a> · <a href={`/pl/${path}`}>Polski</a></p>
  </body>
</html>
```
